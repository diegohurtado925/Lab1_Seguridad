¿Cuál es el punto más débil de PGP?

La contraseña utilizada para proteger la clave privada. Por esta razón se indica 
que debe ser lo mas segura posible. 

¿Cuándo es conveniente utilizar solamente cifrado simétrico?

El cifrado simétrica se busca optimizar el rendimiento y el costo computacional,
cuando se cuenta con un canal seguro para intercambiar la clave y cuando la cantidad
de participanes es reducida.

¿En qué consiste el ciclo de vida del desarrollo de software seguro (etapa por etapa)?

1. Planning (Planificación): Se establecen las consideraciones iniciales de seguridad (Security Considerations) que regirán el proyecto.

2. Design (Diseño): Se implementa el modelado de amenazas (Threat Modelling) para anticipar y mitigar posibles riesgos arquitectónicos.

3. Development (Desarrollo): Se realiza la revisión de código (Code review) para asegurar que se sigan prácticas de desarrollo seguro.

4. Testing (Pruebas): Se ejecutan pruebas integradas de seguridad (Integrated testing) para verificar el comportamiento del software.

5. Release (Liberación / Despliegue): Se garantiza el despliegue con actualizaciones oportunas y seguras (Timely updates).
